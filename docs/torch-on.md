# 횃불ON 시연용 구현 — 2026-11-06

사용자가 정보대만 대상으로 횃불이 페르소나 추천 기능의 구현을 요청했다. 이 작업에 필요한 frontend/와 backend/core/ 변경을 be-a에서 통합한다. 기존 모임 API·시간표 데이터는 유지한다.

- UI: 전역 레이아웃 오른쪽 아래 작은 횃불이(56×72px) 고정 → 클릭하면 왼쪽에 작은 대화창(폭320px, 최대높이460px). 화면이 좁으면 창 폭·높이를 줄인다. 배경 가림 없이 지도·모임 화면을 계속 사용한다. 홍보 문구·예시 질문 버튼 없이 직접 대화하며 Enter로 전송, Shift+Enter로 줄바꿈, Esc·닫기·횃불이 재클릭으로 접는다. 공식 기본/공부/열정 이미지로 대기·처리 중·추천 완료를 표현. 대화 내역 최대10개, 추천 카드→기준 시각을 유지한 강의실 상세→기존 모임 생성. 접었다 열어도 화면 내역을 유지한다.
- 일반 대화: 인사·농담·공부 고민·일반 질문에는 AI가 횃불이 말투로 직접 답한다. 매번 학교/강의실로 유도하지 않는다. ‘시간표’처럼 모호하면 자연스럽게 필요한 내용을 묻는다. 조회하지 못한 학교 공지·학식·개인 시간표는 지어내지 않도록 프롬프트로 제한한다. 일반 대화에는 모임 DB 조회가 필요 없다.
- 문맥: 같은 userId의 최근3턴(사용자300자/응답200자)과 직전 검색 조건을 서버 메모리에 보관, 마지막 사용 후10분 유효·최대256명. 일반 대화 문맥을 OpenAI에 함께 전달한다. DB/로그에는 저장하지 않으며 다른 사용자/날짜에는 전달하지 않는다. 재시작·만료 후에는 초기화, 같은 브라우저의 탭은 문맥 공유. 층 생략/‘층 상관 없어’는 전체 층이며 ‘그럼 3층은?’에는 직전 이용 시간을 유지한다. 새 건물 검색은 새 조건을 사용한다.
- 검색: 정보대/7호관, 현재 화면 기준 시각, 연속 이용 시간, 1~5층. 수업과 현재 모임을 제외하며 향후 모임 시작 시각도 여유 시간의 끝으로 계산. 길게 비는 순으로 최대 3개. 미래 날짜·특정 시작 시각 질문은 현재 지원 범위를 안내한다.
- 정확도: AI는 SearchIntent와 일반 대화 reply를 생성한다. 검색일 때 AI의 reply는 사용하지 않으며 강의실 id·층·남은 시간·이유·최종 문장은 서버의 검증된 데이터로 구성한다. AI가 명시된 2시간/3층을 다른 값으로 해석해도 명시 조건은 우선한다. 조용함·콘센트·좌석 정보는 확인 불가로 안내한다. 일반 대화의 생성 답변은 학교 공식 정보 출처가 아니다.
- 위치: 사용자 승인 확장으로 공식 지도에서 확인한 정보대 좌표까지 Haversine 거리/80m를 올림한 walkMinutes를 반환한다.2km 초과는null과 캠퍼스 밖 안내. 실제 도보 경로 대신 직선거리 환산임을 표시. GPS로 층을 추측하지 않으며 사용자가 ‘3층에 있어’라고 말하면 가까운 층부터 추천한다. 사용자 좌표는 AI/로그/DB/대화 메모리에 남기지 않는다. 출처·필드·검증은 docs/be-a-final-handoff.md 참고. 프론트 위치 수집은 프론트 담당 범위.
- API: POST /api/chat의 외부 요청·응답 필드/에러 형식 유지. 기존 stub 제거. 내부 LLM 출력은 기존 제안의 자유 추천 대신 SearchIntent로 바꿔 환각과 부정확한 시간 추천을 방지한다. 사용자 후속 대화 오류 수정 요청으로 초기 단일 턴 가정에서 짧은 검색 조건 이어받기로 보완했다. 보호 문서 docs/SPEC.md와 contracts/api.md는 수정하지 않았다.
- 장애: 키 없음·timeout·거부·잘못된 모델 출력·호출 제한 시 source=fallback. UI에 ‘기본 응답 · AI 연결 안 됨’을 표시하며 잡담은 AI 연결 장애를 안내한다. DB 오류는 검색 성공으로 숨기지 않는다. 실제 생성 대화는 ‘AI 대화’, 추천 카드가 있으면 ‘AI 추천’으로 표시한다.
- OpenAI: OPENAI_API_KEY는 Render 서버에만 등록. OPENAI_MODEL 기본 gpt-4o-mini. 기존 SDK 사용, 새 패키지 없음. 현재 질문과 최근3턴만 전송(사용자 id/좌표/모임 참여자 데이터 미전송), 질문·키 로그 없음. 한 요청당 한 번 호출, timeout8초·retry0·최대출력700토큰·동시3개. CHAT_DAILY_CALL_LIMIT 기본200회(UTC일, 단일 프로세스 기준, 재시작 초기화, 금액 보장 한도가 아님). 0이면 AI 호출 없이 기본 추천.
