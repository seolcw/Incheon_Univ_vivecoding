# 실제 서비스 화면

- 촬영일: 2026-11-07, 공개 서비스 `https://bingang-web.onrender.com/`
- 화면 조회 시각: 2026-11-10(화) 14:10 KST. 서버 시계·시간표 데이터는 변경하지 않고 서비스의 시연 시각 기능을 사용했습니다.
- 정지 사진의 정보대 3층: 수업 없는 방 4개, 모임 중 1개, 수업 중 1개. 모임을 취소한 뒤 촬영한 영상에는 수업 없는 방 5개와 수업 중 1개가 보입니다. 홈의 13/26은 모임 중인 방을 포함한 수업 없는 강의실 수입니다.
- `두 시간, 같이 공부해요`: 302호, 14:10–16:10, 정원 4명. 독립된 두 브라우저에서 생성·참여하여 1/4 → 2/4를 확인한 후 취소했습니다. 닉네임은 촬영용입니다.
- `ux-demo.mp4`: 실제 브라우저 조작 중 화면을 연속 수집한 186프레임으로 제작한 약 46초 영상입니다. 구간 사이 작업 대기와 긴 캡처 간격을 줄이고 한글 설명을 덧붙였습니다. 캡처 간격은 가변이며 출력은 1280×776, H.264 MP4, 30fps, 무음입니다. 앱의 실제 애니메이션 프레임률이나 API 응답 시간을 측정한 자료는 아닙니다.
- 영상에서는 모임 생성 폼의 시간 슬라이더만 조작하고 제출하지 않았습니다. 새 공개 모임은 만들지 않았습니다.
- `chatbot.jpg`: 인증키 교체·재배포 후 실제 OpenAI 응원 응답과 `AI 대화` 표시를 촬영했습니다. 영상에서는 3층·120분 추천의 `AI 추천` 표시와 추천 카드에서 304호로 이동하는 동작도 확인했습니다.
