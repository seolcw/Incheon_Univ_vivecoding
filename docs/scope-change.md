# 범위 변경 — 정보대 단일 건물 시연

2026-11-06 사용자 결정. 다른 건물의 도면 사진을 구하려면 각 건물에 가야 하므로, 시연은 정보대 1개 건물만 시각화한다.

`docs/SPEC.md`, `docs/pro/spec-v1.md`와 다르면 이 문서가 우선한다. API 계약(`contracts/api.md`)은 변경하지 않는다.

## 결정

| 항목 | 내용 |
|---|---|
| 건물 | 1개. id는 `eng`를 유지하고 화면 이름만 `정보대`. `floors`는 `[1,2,3,4,5]` |
| 강의실 id | `eng-{호수}` 형식 유지 (예: `eng-301`, `eng-506-1`) |
| 데모 장면 | 금 15:10, 3층 301(비어있음)·302(수업 중)·303(모임 중)·304(비어있음). `demo-m1`은 `eng-303` 그대로 |
| 시간표 | 가상 데이터. `eng-301`~`eng-304`의 금요일 시간표는 `spec-v1.md` 5절 값을 유지. 화면과 발표에서 가상 데이터임을 밝힌다 |
| 층 화면 | 격자 대신 도면형 SVG. 좌표는 프론트 데이터로만 두고 API에 추가하지 않는다 |
| 시드에 없는 방 | 도면에 회색으로 표시하고 클릭할 수 없다 |
| B1 | 제외 (대부분 주차장) |
| `/` 화면 | 정보대 블록과, 나머지 건물은 회색 "준비 중" 블록(프론트 고정 표시) |
| 지도 표현 | `docs/SPEC.md` 7절의 "실제 도면·실내 지도"는 이 변경으로 정보대에 한해 MVP로 옮긴다 |
