# 범위 변경 — 정보대 단일 건물, 실제 시간표

2026-11-06 사용자 결정. 시연은 정보대(정보기술대학, 건물 번호 7) 1개 건물만 시각화하고, 시간표는 가상 시드 대신 Firestore `classrooms`의 실제 데이터를 쓴다.

`docs/SPEC.md`, `docs/pro/spec-v1.md`와 다르면 이 문서가 우선한다. API 계약(`contracts/api.md`)의 경로와 필드는 변경하지 않는다.

## 결정

| 항목 | 내용 |
|---|---|
| 데이터 | 배포 설정은 `CAMPUS_SOURCE=seed`. 서버는 `backend/seed/campus.json`(강의실 26개)을 시작 시 메모리에 올린다. `docs/reference/campus-info.json`과 프론트 목업은 이 파일의 사본이다 |
| Firestore | 앱은 `meetups`만 읽고 쓴다. `classrooms`는 시드를 만들 때 쓴 원본이며 요청 중에 읽지 않는다 |
| 건물 | 1개. id `eng`, 화면 이름 `정보대`, `floors`는 `[1,2,3,4,5]`. `lat`, `lng`, `map`은 자리표시 값 |
| 강의실 id | `eng-{호수}` (예: `eng-302`). 프론트는 id를 해석하지 않고 그대로 링크에 쓰고, 도면의 방은 층과 `name`(`302호`)으로 찾는다 |
| 빠진 값 | 원본에 없음. `title`은 `수업`, `capacity`는 `0`(프론트에서 숨김), `tags`는 `[]`. 엑셀에 과목명·정원 열이 있으면 백엔드 B가 채운다 |
| 시간 병합 | 시드는 같은 강의실·요일에서 간격 15분 이하인 수업을 하나로 합친 값이다. 쉬는 시간에 비어 있음으로 깜박이지 않게 한다 |
| 층 화면 | 격자 대신 도면형 SVG. 좌표는 프론트 데이터로만 두고 API에 추가하지 않는다 |
| 시드에 없는 방 | 도면에 회색으로 표시하고 클릭할 수 없다 |
| B1 | 제외 (대부분 주차장) |
| `/` 화면 | 정보대 블록과, 나머지 건물은 회색 "준비 중" 블록(프론트 고정 표시) |
| 지도 표현 | `docs/SPEC.md` 7절의 "실제 도면·실내 지도"는 이 변경으로 정보대에 한해 MVP로 옮긴다 |
| 안내 문구 | 실제 시간표 기준임을 표시한다. 휴강·보강은 반영되지 않고, 시간표에 없는 시간은 문이 열려 있다는 뜻이 아니다 |
